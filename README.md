# DineEase — Vanilla HTML/CSS/JavaScript

This is the DineEase project converted from the original React/TypeScript implementation to plain HTML, CSS and JavaScript.

## Included features
- Responsive restaurant landing page
- Dynamic menu and category filtering
- Search
- Favorites saved with LocalStorage
- Shopping cart with quantity controls
- Free delivery calculation over $50
- Checkout form validation
- Order confirmation
- Light/dark mode saved with LocalStorage
- Original local food/hero images

## Structure
- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/`
